# WeatherRadar
It monitors temperature and humidity and can be controlled via a PC. This project serves as an example of how to connect an Arduino to a computer. It's easy to use and straightforward!

# How to use
It's very easy to use, and you can get everything up and running in 10 minutes. Just follow the steps and you'll get the results you want.
1. Download the archive and extract it to a folder of your choice.
2. Now we need to upload the code to the Arduino. To do this, navigate to / -> arduino_source. If you’re using PlatformIO (*recommended*), simply open the WeatherRadar folder as a project and upload the code to the board. If you’re using the Arduino IDE, go to the script_only folder and open it in the Arduino IDE. Then install the LiquidCrystal and DHT libraries. Then upload the code to the Arduino.
3. Now it’s time for Python. Run the script from the python_source folder (don’t delete the help.txt file—it contains information that will help you), launch the program, and type “help” to see all the commands (the “ft” command doesn’t work yet). One command will be hidden—it’s “rf”—and we’ll cover how to use it later. You can go through the basic instructions. 
4. Done
